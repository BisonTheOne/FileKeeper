This platform is a secure file management system built around USB-based authentication integrated with Linux PAM services.

The project combines hardware-backed authentication, FTP-based storage services, and a web interface designed for secure remote file access.

Authentication is enforced through a physical USB token. When a valid token is connected to the server, users are allowed to authenticate and access protected resources. Without the token, access is denied automatically.

Core technologies used in this project include:

  • Linux PAM (Pluggable Authentication Modules)
  • Bash scripting
  • Flask web framework
  • vsftpd FTP server
  • Systemd automount and bind mounts
  • Logrotate for authentication log management

The web interface provides:

  • File upload and download
  • Remote file management
  • Session-based authentication
  • Minimal dark-themed user interface

This project was developed as a bachelor thesis focused on Linux authentication systems, secure access control, and service integration.
